# Skill Authoring System

This directory contains rules for making backend knowledge easy for coding agents to discover and use without overloading context.

## Documents

- `INVOCATION.md` — model-invoked vs user-invoked skills and Codex metadata consistency
- `CONTEXT_POINTERS.md` — how descriptions route agent attention
- `COMPLETION_CRITERIA.md` — observable definitions of "done"

Repository-level scope rules live in `SCOPE.md`.

The goal is not to make skill files longer. The goal is to make routing, disclosure, completion, and verification more deterministic.
